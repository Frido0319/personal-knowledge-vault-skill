## Boundaries

- Acceptance data is synthetic. No personal chat history, private repository, secret, or real vault content is committed here.
- Windows compatibility is verified on GitHub-hosted native Windows runners, not on every Windows desktop configuration.
- The runtime is local-first and deterministic; it does not silently send source content to a hosted LLM.
- Source ingestion remains opt-in. Sensitive history and chat adapters require explicit secondary authorization.
- GitHub publication and backup operations remain separate, previewable integration steps.
