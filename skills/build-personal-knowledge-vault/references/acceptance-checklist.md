# 验收清单

交付前逐项记录 PASS、FAIL 或 NOT VERIFIED，不用“基本完成”替代证据。

## 安全与范围

- Vault/Data 位于公共源码仓库外，路径互不包含。
- 来源清单与用户逐项授权一致；敏感导出有二次授权，WeFlow/QQ 默认关闭。
- 未扫描整个 Home、浏览器、凭据目录或聊天软件内部目录。
- 审计与终端输出不包含 token、私钥、Cookie 或真实聊天正文。
- GitHub 知识仓库在上传前后均验证为 `PRIVATE`。

## 功能

- `doctor` 核心检查通过；缺失可选工具被标为 optional。
- 首次 `update --apply` 生成首页与 L0-L5 层级；全局导航只突出 L0-L3。
- 第二次相同更新为幂等，不重复页面。
- 项目页包含用途、状态、已确认成果、下一步、关键资料、本机路径与可用的固定 commit 链接。
- 语义提案先出现在 `_staging`，人工 promote 后才进入正式知识目录。
- 内建搜索能找到一个项目、一个学习条目和一个已批准知识条目。

## 平台与界面

- Linux 使用 systemd user；Windows 使用原生 Task Scheduler 且标准模式无需管理员。
- 每日任务只执行知识更新，不执行 upgrade 或自动审批。
- Web 仅监听回环地址；Host、CSRF、CSP、body 上限和动作白名单生效。
- 实际检查桌面与移动截图：无重叠、横向溢出、截断、不可达控件或空白主视图。

## 恢复与交付

- 备份状态有时间、目标和成功证据；至少完成一次合成恢复演练。
- 记录 Vault、Data、config、备份、私有镜像和控制台 URL 的精确位置。
- 明确区分已验证本机结果、CI 平台结果和仍需用户真实数据/真实桌面确认的事项。
- 输出已授权来源、页面数、待审核数、索引状态、备份快照和私有镜像 commit。
