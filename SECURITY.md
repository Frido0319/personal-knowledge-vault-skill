# Security Policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Frido0319/personal-knowledge-vault-skill/security/advisories/new). Do not open a public Issue containing real Vault content, chat exports, local paths, credentials, tokens, or private repository details.

Include the affected version, operating system, minimal synthetic reproduction, and expected privacy boundary. Remove all user data before attaching logs or screenshots.
